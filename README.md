# Lemook Gardens

Welcome to **Lemook Gardens** — a modern website for a restaurant and BnB, offering a unique dining and accommodation experience surrounded by nature.

## Overview
Lemook Gardens is a vibrant restaurant and bed & breakfast, providing guests with delicious cuisine, refreshing drinks, and comfortable stays in a lush garden setting. This website allows visitors to explore the menu, drinks, BnB options, gallery, and make reservations online.

## Features
- Modern, responsive design
- Dedicated pages for About, Menu, Drinks, BnB, Booking, Contact, and Gallery
- Online reservation form for dining and BnB
- Photo galleries for food, drinks, and accommodation
- Contact information and social media links

## Getting Started
1. **Clone the repository:**
   ```sh
   git clone https://github.com/Aubrey359/lemook-gardens2.git
   ```
2. **Open the project folder:**
   - All main files are in the root directory (HTML, CSS, images).
3. **Run locally:**
   - Open `index.html` in your browser to view the site.
   - For dynamic features (like booking), you may need a local server (e.g., Node.js/Express).

## Project Structure
- `index.html` — Homepage
- `about.html` — About Lemook Gardens
- `menu.html` — Food menu
- `drinks.html` — Drinks menu
- `bnb.html` — BnB accommodation
- `booking.html` — Reservation form
- `contact.html` — Contact page
- `gallery.html` — Photo gallery
- `style.css` — Main stylesheet
- Images — Food, drinks, and BnB photos
